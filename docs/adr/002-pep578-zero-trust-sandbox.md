# ADR 002: Rootless PEP 578 Runtime Audit Hooks and Resource Limits Over OS Chroot

## Status
Accepted

## Context
Executing untrusted code generated by AI models requires strict defense-in-depth against credential theft, unauthorized file access, network exfiltration, and fork-bomb DoS attacks.
Traditional isolation approaches suffer from critical flaws:
1. **OS `chroot()` Requires Root (`sudo`):** On Linux and macOS, calling `os.chroot()` raises `PermissionError` when executed by standard developers or unprivileged CI runners (e.g., GitHub Actions, GitLab CI).
2. **Docker Dependency Overhead:** Requiring Docker adds multi-gigabyte container dependencies, daemon requirements, and platform friction.
3. **Subprocess Escape:** Pure environment variable scrubbing does not prevent a running Python process from opening raw network sockets or calling `open()` on unauthorized directories outside the project root.

## Decision
We implement a zero-trust, rootless sandbox (`apex_council/security/sandbox.py`) using **PEP 578 CPython Runtime Audit Hooks (`sys.addaudithook`)** and **Kernel Resource Quotas (`resource.setrlimit`)**:
- **C-Level Event Interception:** Registers an immutable audit hook before untrusted code runs:
  - `os.system`, `subprocess.Popen`, `os.spawn*` ➔ Immediately raises `PermissionError` (prevents subshell escapes).
  - `socket.connect`, `socket.bind`, `socket.send*` ➔ Immediately raises `PermissionError` (prevents data exfiltration).
  - `open` ➔ Intercepts file writes outside the authorized project root or system temp folder.
  - `ctypes.dlopen`, `ctypes.dlsym` ➔ Rejects direct interpreter memory tampering.
- **Kernel Resource Limits (POSIX):**
  - `RLIMIT_CPU`: Soft 4s, Hard 5s (stops infinite CPU loops at the kernel level).
  - `RLIMIT_AS`: 512MB RAM cap (defeats out-of-memory DoS).
  - `RLIMIT_NPROC`: Max 16 processes (defeats fork bombs).
  - `RLIMIT_FSIZE`: Max 15MB file writes (defeats disk flooding).

## Consequences
- Runs 100% in unprivileged user-space on Linux, macOS, and Windows without `sudo` or Docker.
- Intercepts unauthorized operations at the CPython C-interpreter level before system calls reach the OS.
